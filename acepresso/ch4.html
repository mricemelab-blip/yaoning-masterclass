04

运动前健康筛查

Pre-Participation Health Screening

识别谁需要先看医生，确保安全运动。掌握 ACSM 三轴决策算法、PAR-Q+ 三色判定、ACE ABC 沟通法，以及药物对心率的影响。

板块一 运动的固有健康风险

规律运动可降低心血管疾病（CVD）、肺部疾病、代谢性疾病、某些癌症、焦虑抑郁和过早死亡风险。但运动存在固有风险：对健康个体，中等强度运动不会引发心血管或肌肉骨骼危险事件。

风险升高的三类人群（风险三角）：

  1. 运动习惯不佳
  2. 已患病个体（已诊断 CVD / 代谢 / 肾脏疾病）
  3. 计划进行接近极限强度运动的个体

有潜在 CVD 的个体进行不习惯的剧烈身体活动时，运动相关的急性心肌梗死（AMI）和心源性猝死（SCD）风险最高。无症状个体即使高强度运动，心血管不良事件风险仍极低。

运动整体有益，但"不习惯的剧烈运动 + 已患病/有症状个体"这个组合确实存在风险。筛查用于识别风险，不用于拒绝客户。
💡 记忆技巧
风险三角：不习惯 + 已患病 + 接近极限，三者齐备才高危。最高风险场景 = 有潜在 CVD + 突然进行不习惯的剧烈运动（如久坐多年的中年人突然参加篮球比赛）。

板块二 ACSM 运动前筛查算法

筛查基于三个风险调节因素（ACSM 2018 更新版）：①个人目前身体活动水平 ②是否确诊 CVD/代谢/肾脏疾病 ③有无相关体征/症状。

"定期运动"的定义：过去 3 个月内，每周至少 3 天，至少 30 分钟有计划、有组织的中等强度身体活动。口诀："3-3-30"。

不参加定期运动者的筛查决策

条件是否需要医学许可建议运动强度
无 CVD/代谢/肾脏疾病 + 无体征/症状不需要轻度→中等→逐步提高到高强度
已知患有 CVD/代谢/肾脏疾病但无症状需要轻度→中等→根据许可逐步提高
有 CVD/代谢/肾脏疾病的体征/症状需要先获许可，再轻度→中等→逐步提高

参加定期运动者的筛查决策

条件是否需要医学许可建议运动强度
无 CVD/代谢/肾脏疾病 + 无体征/症状不需要继续中等或高强度
已知患有 CVD/代谢/肾脏疾病但无症状中等强度不需要；高强度需要中等强度继续；获许可后逐步提高
有 CVD/代谢/肾脏疾病的体征/症状中断运动，需要医学许可获许可后继续
💡 记忆技巧
口诀："症状是老大，有病看强度，无病随便动"。定期运动 + 有疾病无症状 + 中等强度 = 可考虑免除许可（ACSM 原文 "may consider"，注意不是"不需要"）。

需警惕的体征/症状（必背）

  • 可能因心肌缺血导致的胸、颈、颌、手臂等部位疼痛/不适
  • 休息或轻度用力时呼吸急促（呼吸困难）
  • 端坐呼吸 / 阵发性夜间呼吸困难
  • 眩晕或晕厥
  • 踝水肿
  • 心悸或心动过速
  • 间歇性跛行
  • 已知的心杂音
  • 日常活动时异常疲劳或呼吸急促
💡 记忆技巧
口诀："胸颈颌臂疼、呼吸休息急、晕眩踝肿悸、跛行杂音疲"。心脏缺血样疼痛 + 呼吸困难 + 晕眩 = 立刻停，三大红灯。

强度%HRR / %VO₂RMETRPE（经典）
低<40%2-2.99-11
中40-59%3-5.912-13

💡 记忆技巧
口诀："低39中59高60"——记住三个关键百分数。RPE 12-13 = 中等强度 = 说话测试能说句子但不能唱歌。
🎯 教练贴士
ACSM 筛查算法关键区分点：① "有无疾病"和"有无症状"是两件事，有症状不论疾病状态都要医学许可；② 定期运动者比不定期运动者门槛低；③ "体征/症状"是最强触发器，有症状就停。不要诊断，转介优先——不要跟客户辩论症状原因。

板块三 运动前健康筛查问卷

问卷分 3 步：①症状（6项）→ ②目前活动（是否定期运动）→ ③身体状况（9项疾病勾选）。

  • 第1步有任何勾选 = 停止，需医学许可
  • 第2步：是否满足定期运动定义
  • 第3步：心脏病发作/心脏手术/起搏器/心脏瓣膜疾病/心力衰竭/心脏移植/先天性心脏病/糖尿病/肾脏疾病
问卷三步对应筛查算法三个关键信息：症状触发许可（第一步）、运动史调节门槛（第二步）、疾病状态决定强度限制（第三步）。三步环环相扣，缺一不可。

板块四 ACE ABC 沟通法

当筛查结果指向需要医学许可时，用 ABC Approach（对话式，非面试式）与客户沟通：

  • A — 提问（Ask）：开放性问题了解客户目标与需求
  • B — 打破障碍（Break Barriers）：发现阻碍客户参与计划的潜在问题
  • C — 协作（Collaborate）：共同努力实现目标

关键原则：医学许可不是拒绝帮助，是为了提供正确的帮助。不能让医学许可要求成为运动的障碍。许可等待期间可以鼓励客户做低强度活动（走路、拉伸等），保持运动势头。

🎯 教练贴士
核心心态：把客户当队友，把医生当顾问。医学许可是起点，不是终点。提供医学许可表格模板，写清楚计划的运动类型，让医生有据可依。避免"全有或全无"思维。

板块五 抗阻训练筛查

目前尚没有充分证据证实低到中等强度抗阻训练需要进行正式的预先筛查（ACSM, 2018）。现有资料有限，但并发症风险似乎较低。

🎯 教练贴士
关键区分："不额外要求筛查" ≠ "不需要筛查"。所有客户仍应完成通用的运动前健康筛查。抗阻训练筛查宽松是因其固有风险低，通用健康筛查仍适用于所有客户。

板块六 PAR-Q+ 自我筛查

PAR-Q+（Physical Activity Readiness Questionnaire-Plus）= 身体活动准备程度问卷。既是客户的自我筛查工具，又是私教获取更多信息的额外筛查要素。编制目的：减少不必要的运动障碍（循证方式）。

分4页：第1页7个一般健康问题 → 第2-3页后续深入问题（按疾病类别分支）→ 第4页结果判定。

结果含义行动
绿色（全否）可以进行更多身体活动建议慢慢开始，逐步加强，目标每周150分钟中等强度
红色（有是）需进一步评估完成 ePARmed-X+ 和/或咨询运动专业人员
黄色（延迟）暂时不宜增加活动感冒/发烧→等好转；怀孕→告知医生；暂时性健康问题→先咨询医生
💡 记忆技巧
口诀："绿 = 放行 / 红 = 深入 / 黄 = 等等"。PAR-Q+ 设计哲学是"默认安全，例外排除"，假设大多数人是安全的，只排除明确有问题的少数人。PAR-Q+ 由加拿大开发，当前版本2020，可在 www.eparmedx.com 获取。

板块七 心脏康复与健康机构中的患者

在心脏康复等临床环境中，应使用比通用筛查更深入的工具。建议使用 AACVPR（美国心血管和肺康复协会）的风险分层标准，基于运动能力（MET水平）、左室射血分数（LVEF）、心律失常类型等多维度评估。

场景筛查工具
普通健身房ACSM 算法 + PAR-Q+
心脏康复中心AACVPR 风险分层（更深，基于运动能力、心功能、心律失常等多维度）
筛查深度与风险环境匹配。普通场所用通用工具，高风险场所用专业工具。临床环境中的任何异常体征/症状都必须通报客户医生。

ACSM 运动前筛查决策流程

适用场景：所有新客户首次训练前必须完成的筛查流程
发放筛查问卷：所有客户必须填写运动前健康筛查问卷（或 PAR-Q+），不可跳过
第一步：症状筛查：检查6项症状（胸痛、呼吸困难、眩晕等），任何一项阳性 = 停止，需医学许可
第二步：运动史判定：是否满足"3-3-30"定义（过去3个月、每周≥3天、每次≥30分钟中等强度）
第三步：疾病状态确认：检查9项疾病（心脏病发作/手术/起搏器/瓣膜疾病/心衰/移植/先天心脏病/糖尿病/肾脏疾病）
交叉决策：运动史 × 疾病 × 症状 三轴判定，参照筛查算法表格确定是否需要医学许可
记录归档：保存问卷原件，记录判定结果和后续建议

医学许可沟通流程（ABC 法）

适用场景：筛查结果显示客户需要医学许可时
A — 提问（Ask）：用开放性问题了解客户的运动目标和期望，如"您希望通过训练达到什么效果？"
B — 打破障碍（Break Barriers）：发现并处理阻碍因素，如客户担心"医生会说不能运动"——解释许可是为了更安全地运动
C — 协作（Collaborate）：与客户共同制定过渡方案，提供医学许可表格（写清计划运动类型），让医生有据可依
等待期安排：告知客户在等待医生签字期间，可以从低强度活动开始（走路、拉伸等），保持运动势头
获取许可后：客户获医生签字同意后，根据许可内容制定正式训练计划，开始训练

PAR-Q+ 使用与管理流程

适用场景：作为通用筛查的补充工具或客户自我筛查
发放 PAR-Q+：客户填写第1页7个一般健康问题
判定分支：全否→绿色放行；有是→进入第2-3页按疾病类别分支的深入问题
三色结果处理：绿色=建议逐步增加至每周150分钟中等强度；红色=完成 ePARmed-X+ 或咨询专业人员；黄色=暂时延迟（感冒/发烧/怀孕等先处理）
重要提醒：PAR-Q+ 全绿 ≠ 零风险，只是目前不需要进一步评估。PAR-Q+ 不能替代医学检查
